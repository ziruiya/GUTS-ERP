# GUTS-ERP

**版本：0.17.0**

## 登录状态保持

登录状态会在使用期间自动续期，持续活动时不会因访问令牌到期而要求重新登录。连续 30 天未活动后需要重新登录；手动退出会撤销当前浏览器的登录会话。

## 新 VPS 部署（Debian 12 + 宝塔）

### 1. 准备 VPS 和数据库

在宝塔安装并启动 MariaDB 10.11（部署目标版本为 10.11.10；尚未连接生产 VPS 实测），确保数据库在
`127.0.0.1:3306` 监听。不要把数据库端口开放到公网。准备好域名，并将 DNS 指向 VPS。

### 2. 运行安装程序

用 SSH 登录 VPS，以 `root` 身份执行。安装程序会安装 Node.js 24 和 PM2、创建 ERP 数据库
及专用数据库账号、生成 `.env`、迁移数据库、创建首个管理员并启动 ERP。

```bash
curl -fsSL https://raw.githubusercontent.com/chiyamahisayoshi/GUTS-ERP/main/deploy/install.sh -o install.sh
bash install.sh
```

按提示输入 MariaDB `root` 密码和 ERP 访问域名（例如 `https://erp.example.jp`）。安装完成时
管理员密码只显示一次，请立即保存并妥善保管。若安装程序报告数据库未启动或没有监听
`127.0.0.1:3306`，先在宝塔启动 MariaDB，再重新运行安装命令。

### 3. 配置域名和 HTTPS

在宝塔「网站」中添加域名、申请并启用 HTTPS 证书，将网站反向代理到：

```text
http://127.0.0.1:3000
```

确保反向代理传递 `Host`、`X-Real-IP`、`X-Forwarded-For` 和 `X-Forwarded-Proto` 请求头。
首次配置后，用浏览器打开 `https://你的域名`。

### 4. 验证安装

在 VPS 上执行：

```bash
erp status
curl -fsS https://你的域名/health
```

健康检查应返回 `{"status":"ok"}`。如启动失败，查看服务日志：

```bash
erp logs
```

数据库连接和 JWT 配置保存在 `/www/wwwroot/guts-erp/.env`，仅允许服务器运行账号读取。
修改配置后运行 `erp restart`。更新时先备份数据库，再运行 `erp update`。

## 修改管理员密码

若还不能登录 ERP 页面，可通过 SSH 登录服务器并运行 `erp passwd 管理员登录名`。命令会生成一个新密码并只显示一次，请马上保存；省略登录名时默认重置 `admin` 账户。

也可在「门店管理」中打开总部门店详情，再打开「管理账户」，找到管理员账户并点「修改密码」。新密码长度为 12～128 个字符。已登录设备不会因此自动退出。

## 账号管理

「门店管理」列表中选择门店可查看地址、电话、加入日期和车辆数量，也可编辑地址和电话。打开「店铺账户」可查看该门店账户、创建账户、编辑权限或修改密码；管理员账户会单独标识。管理员可对每个启用的门店账户点击「登录」，以该账户自己的权限进入 ERP；右上角「返回管理面板」可恢复管理员会话。

## 管理员门店操作

本部管理员创建车辆和预约时默认使用本部所属站点，无需再选择登记门店。门店详情中的「停止门店」会停用登录并保留历史数据；管理员可随时选择「重新开店」恢复。

## 车辆登记

车辆新增表单与 Parking 的登记字段保持一致。系统会为现有站点（包括总部）补齐缺失的 Parking 默认车辆类别、选项、状态、评估项和损伤类型；新建站点也会初始化同一套默认目录。门店可在停车场设置中继续自定义这些目录，包括新增、编辑和删除车辆选项及处理状态。车辆档案还可保存车检到期日和法定点检日，并在车辆信息中查看或修改；日期目前仅保存为车辆资料，提醒功能尚未启用。

## 停车场与车辆同步

「车辆布局」中的「停车场管理与设置」集中管理停车区域、停车场优先车辆类别、门店位置、距离、车辆类别、选项及处理状态。停车场间的优先类别按从高到低的顺序填写，并用逗号分隔。

车辆同步会在 ERP 启动时对账，并在车辆或预约变更后按所属门店触发；失败时会记录错误并自动重试。无需手动点击同步。预约状态变化后，停车看板会实时刷新车辆的预约或出租状态。门店和停车场可登记 Google Maps 链接；链接包含经纬度时，系统会在本地计算直线距离，不会将地址发送给外部服务。直线距离不等于行车距离；Google Maps 短链接或不包含坐标的地址需要手动填写距离，行车时间也需按实际路线手动填写。

## 客户管理与预约

「客户管理」按所属门店隔离客户资料，可维护姓名、假名、电话、邮箱、出生日期、地址、紧急联系人及工作单位 / 学校；除姓名和电话外，其他资料均为选填。创建预约时可按姓名、假名或电话号码搜索并选取已有客户，姓名和电话会自动填入预约。未选取已有客户时，保存预约会在同一事务中创建只包含姓名和电话的新客户。

预约车辆通过「期望类别」和出租、归还时间查询该门店内的空闲车辆，并显示车辆所在停车区域。ETC、车载器、禁烟 / 吸烟、导航和雪地轮胎等勾选条件会同时应用；不勾选时显示时间与类别符合条件的全部空闲车辆。

## 版本号规则

每次发布都更新版本号：兼容性 bug 修复增加 patch，后向兼容的功能更新增加 minor（例如
`0.5.0` → `0.6.0`），破坏兼容性的更新增加 major。`package.json` 和 `package-lock.json`
中的版本必须保持一致。
